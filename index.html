Quando algo dá errado

401Test connection falha com “Unauthorized”
Credential was not sent or was of an unsupported type for this API … HTTP 401 Unauthorized

O dbt chegou ao warehouse, mas o token foi recusado. Quase sempre é um destes: campo Token vazio, token copiado pela metade, ou o Token ID colado no lugar do token.

Solução: gere um novo token no Databricks, copie o valor que começa com dapi e cole de novo em Credenciais.

401Funcionava e parou depois de algumas semanas

O token expirou (ele tem a validade escolhida na criação). Gere outro e troque apenas o campo Token nas credenciais. O restante continua igual.

gitA opção GitHub não aparece na etapa Repository

A conta do dbt ainda não está ligada ao GitHub. Vá em Account settings → Integrations → GitHub → Link, autorize e volte ao projeto.

gitO repositório não aparece na lista

O app do dbt foi instalado com acesso só a alguns repositórios. No GitHub, abra Settings → Applications → dbt Cloud → Configure e inclua o repositório.

schemaAs tabelas saem com o nome de outra pessoa

O schema foi copiado de um tutorial (ex.: dbt_lmiranda). Troque para o seu em Credenciais de desenvolvimento e rode de novo.

catalogErro de catálogo ou tabela não encontrada

Com Unity Catalog, informe o catalog na conexão. No Free Edition o padrão é workspace; confira o nome exato no menu Catalog.

lentoA primeira execução demora

O SQL Warehouse desliga sozinho quando fica ocioso. A primeira consulta espera ele ligar; as seguintes são rápidas.
